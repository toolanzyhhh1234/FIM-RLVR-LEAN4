## Ministral-3B GSPO run (local)

Goal: replicate the Ministral-3 3B RL script run and capture env + pip issues.

### Environment notes
- We created a fresh `.venv` with `uv venv .venv`.
- `pip` may be missing when the venv is created by `uv`. If `pip` is missing:
  - `/workspace/FIM-RLVR-LEAN4/.venv/bin/python -m ensurepip --upgrade`
  - `/workspace/FIM-RLVR-LEAN4/.venv/bin/python -m pip install -U pip`
- If `pip` installs to the wrong environment, force the path:
  - `/workspace/FIM-RLVR-LEAN4/.venv/bin/python -m pip ...`

### Transformers / Unsloth compatibility warning
We installed `transformers` dev from GitHub to satisfy the Ministral-3 model check:
```
pip install --upgrade git+https://github.com/huggingface/transformers.git
```
`pip` prints a dependency conflict warning (Unsloth pins `transformers<=4.57.3`), but **the run still works** and Unsloth is compatible with the dev version for this test.
Example warning (keep for reference, no action needed):
```

unsloth ... requires transformers<=4.57.3, but you have transformers 5.0.0.dev0
```
